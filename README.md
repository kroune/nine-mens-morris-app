## Setting up a Workspace

Our project is for android, so make sure to use [android studio](https://developer.android.com/studio) or smth similar.

1. Clone the repository using `git clone https://github.com/kroune/nine-mens-morris-app`.
2. CD into the local repository.
3. Run `./gradlew build`.
4. Open the folder as a Gradle project in the IDE.
